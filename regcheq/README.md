# Regcheq — Herramienta Local (Python)

Servidor Flask local para análisis de perfiles AML/KYC vía la API de Regcheq.

## Configuración

```bash
cp config.py.example config.py
# Editar config.py con tu API key real
```

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

```bash
python app.py
# Abrir http://localhost:5050
```
